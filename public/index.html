VButton

One action per screen gets the primary variant. Everything else steps back.

Primary · Secondary Small · Medium · Large
Live Playground

Visual style — primary for main actions, secondary for supporting actions

sizesmall \| medium \| large

Touch target size — maps to token heights

disabledboolean

Non-interactive state; removes hover/focus, announces to AT

Snippet
<VButton />

Usage Notes

  • Use primary for the main CTA on a screen; secondary for everything else.
  • Disabled buttons are non-interactive and announce their state to screen readers.
  • Sizes scale via tokens: small (24px), medium (32px), large (40px).
  • All colors use semantic tokens — works in light/dark mode automatically.

Snippet
<VInput />

Usage Notes

  • State is explicit — never conveyed by color alone. Screen readers announce state changes.
  • Hint text provides context without cluttering the label.
  • Type attribute supports text, email, password, search — native validation kicks in.
  • Error state pairs with aria-invalid and descriptive error message.

Usage Notes

  • Default is flat (no shadow) — elevation is opt-in via elevated prop.
  • Padding scales via tokens: none (0), small (16px), medium (24px), large (32px).
  • Border uses --border-subtle — visible but quiet in both themes.
  • Works as a clickable card when onClick is provided (adds cursor: pointer).

Usage Notes

  • Never rely on color alone — pair with text or an icon for accessibility.
  • Dot mode renders a 8px circle — perfect for online/away/offline indicators.
  • Outline style uses a transparent background with a colored border.
  • All variants use semantic tokens — respect dark mode automatically.

VModal

Overlay dialog surface — focus-trapped, escape-dismissible.

Overlay · DismissibleBackdrop blur
Live Playground
Configure props to see the modal specimen
titlestring

Dialog heading — rendered as h2

dismissibleboolean

When false, only primary action can close

Snippet
<VModal />

Usage Notes

  • Backdrop is blurred via CSS — reduces visual noise behind the dialog.
  • Press Escape to close when dismissible is true.
  • Clicking outside the dialog also dismisses when dismissible.
  • Focus is trapped inside the modal while open.
